Platform capabilities

Built for every role on campus

A complete campus management system — from secure authentication and analytics to student records and document storage.

Security

Secure Authentication

Cookie-based JWT with automatic token rotation, progressive login lockout after failed attempts, and permanent block protection.

Workflow

Admin Approval Workflow

New registrations start as inactive. Admins review, activate accounts, and complete student profiles from a dedicated pending-registrations list.

Access Control

Role-Based Access

Four roles — Admin, Editor, Teacher, and Student — each with strictly enforced permissions at both the API middleware and UI route-guard levels.

Core Module

Student Management

Full student lifecycle — create profiles, assign multiple courses with batch years, track status, edit details, and manage guardian information.

Administration

User Management

Admins create, update, and delete users across all roles. Inline role changes, account activation, and cascade-delete for student accounts.

Documents

Document Uploads

Students upload documents and photos securely to Cloudinary. Staff can add, view, and remove files per student record with safe rollback on failure.

Analytics

Analytics Dashboards

Role-specific dashboards with doughnut, bar, line, and polar charts showing enrollment stats, course-wise breakdowns, and recent activity per user.

Security

Session Management

Users see all active login sessions by device and IP. Revoke a single device, or sign out of every session simultaneously from one screen.

Account

Profile Management

Every user can upload a profile picture, update personal information, and change their password — with immediate session invalidation on change.

UX

Adaptive Navigation

The sidebar and breadcrumbs update dynamically based on the logged-in user's role, hiding irrelevant sections and surfacing what matters.

Infrastructure

Cloud Storage

Profile pictures and student documents are stored on Cloudinary with automatic cleanup on updates and transactional rollback on errors.

Design

Responsive Design

Every screen adapts seamlessly across mobile, tablet, and desktop using PrimeNG responsive components and CSS Grid breakpoints.
